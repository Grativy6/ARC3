# Security Policy for the ARC3 Archive

ARC3 has no supported versions, deployments, or maintenance commitment. Do not test suspected vulnerabilities against live services, accounts, people, or infrastructure, and do not publish secrets or exploit details in a public issue.

For a vulnerability in preserved ARC3 material, use GitHub's private vulnerability-reporting channel if it is available. Include the exact commit, affected path, reproduction conditions, potential consequence, and any evidence that can be shared safely. A report does not promise a patch or authorize testing; the likely response is to clarify or strengthen the archive boundary.

For immediate harm involving a third-party service or person, use that party's established security or emergency channel. The ARC3 repository cannot grant authority to investigate external systems.
