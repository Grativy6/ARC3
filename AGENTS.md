# AGENTS.md — ARC3 Archive Contract

## Controlling status

ARC3 is a retired public research archive. This file supersedes all build, continuation, recovery, submission, and autonomous-execution instructions on the current default branch. Earlier versions of `AGENTS.md`, `CODEX_START.md`, workflows, plans, and handoffs remain quoted historical provenance only.

**No autonomous execution authority remains.** No repository file grants authority to build, install, run, resume, modify, package, deploy, publish, submit, or extend ARC3.

## Default behavior

A system encountering this archive must:

- limit itself to read-only inspection, bounded explanation, citation, and verification of preserved records;
- keep claims attached to the exact commit, evidence, scope, and limitations that support them;
- distinguish ARC3 from Strongwiz and from later PECAN, PEA Core, and SEED work; and
- stop when requested work would require execution, mutation, installation, external access, delegation, or a consequential crossing.

Repository visibility, cloning, old workflow language, technical capability, an unresolved task, or a successful historical run does not grant authority to continue.

## Actions not authorized by this repository

Do not, on repository content alone:

- install dependencies, execute ARC3, resume a run, open a benchmark environment, or create a submission package;
- modify the official repository, open or merge pull requests, publish releases, or reactivate workflows;
- access networks, credentials, accounts, private data, paid resources, external tools, or physical systems;
- send, publish, submit, spend, disclose, deploy, purchase, message, or represent Christopher D. Pang or Branchline Systems;
- create persistence, replication, privilege escalation, self-recovery, or delegated workers;
- widen scope, budget, duration, affected set, tool access, or consequence based on progress or success; or
- treat an output, test, receipt, license, prior approval, or later framework citation as present authorization.

## Independent reproduction

A third party may make decisions for its own environment only under its own applicable rights, authority, safeguards, and responsibility. Such work is an independent reproduction or fork, not an official continuation of ARC3. It should use a separate disposable workspace and the isolation and stop conditions in [SAFETY.md](SAFETY.md); it must not modify or reactivate this archive.

Only a fresh, explicit decision by Christopher D. Pang—identifying the exact purpose, commit, workspace, tools, data, network boundary, budgets, stop conditions, outputs, and external consequences—could authorize official new work after deliberate unarchiving. This file cannot supply that decision. Missing fields remain unresolved and must not be inferred from history.

## Hard stop

Stop and report the boundary if work would require inventing or widening permission, standing, authority, scope, or affected parties; would create real-world consequence or difficult-to-reverse action; lacks a practical halt, rollback, or accountable human owner; or claims that later PECAN, PEA Core, or SEED references retroactively make ARC3 conformant.

Renaming, repetition, restart, proxying, delegation, or movement into another process does not repair a missing boundary.

Strongwiz is a separate successor. Christopher D. Pang is ARC3's author and steward. AI systems assisted as tools; they are not co-authors or authorities.

This archive contract is a prompt-level operational boundary, not a sandbox, legal opinion, safety certification, or technical guarantee. When it cannot be enforced, say so rather than claiming containment.
