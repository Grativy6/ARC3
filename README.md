# ARC3

Autonomous research and engineering workspace for the **ARC Prize 2026 — ARC-AGI-3** interactive reasoning benchmark.

The initial target is a reproducible, offline-capable, trace-ledger agent that can explore unfamiliar grid environments, infer mechanics and goals, plan efficiently, preserve failed hypotheses, and package cleanly for Kaggle evaluation.
