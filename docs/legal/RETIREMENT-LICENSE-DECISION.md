# ARC3 retirement and prospective license decision

Status: **OWNER-APPROVED RETIREMENT TRANSITION**

Owner: **Christopher D. Pang**
Decision date: **2026-09-02**

## Decision

Christopher D. Pang directed that ARC3 be placed in the strongest practical, honest public-retirement posture available to reduce unethical use. The transition:

- ends active development and supported execution;
- removes runnable source, scripts, packaging metadata, tests, launch instructions, and active workflows from the default branch;
- adds explicit safety, responsible-use, archive, and no-authority boundaries;
- closes unfinished active work and archives the GitHub repository;
- records the exact pre-retirement public refs and license identities; and
- reserves all rights in first-party material first introduced by the retirement transition or later unless a file expressly states otherwise.

## Historical-license boundary

The owner previously released specified ARC3 snapshots under MIT-0. Those grants cannot honestly be presented as revoked by this transition. The exact MIT-0 text and every public branch tip visible before transition are preserved in [pre-retirement-public-refs.json](pre-retirement-public-refs.json). Public refs without a root license are recorded without a new retrospective conclusion.

The retirement head is mixed: earlier material may remain available under historical terms, while new retirement contributions receive no new public license. Packaging metadata has been removed from the default branch so it cannot misleadingly describe the mixed retirement tree as a current distributable package.

## Ownership and third-party boundary

Git history and visible pull-request metadata identified only the `Grativy6` account, using two email identities, as a commit author. This is evidence, not a legal determination. Third-party source, data, dependencies, and documentation retain their own terms; this decision does not relicense them. See [../../THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

## Safety and authority limit

Copyright restrictions, archive settings, and written warnings create friction and preserve the author's position; they are not technical containment and cannot prevent a determined person from using an earlier public copy. A license also does not create consent, ethical approval, operational authority, or safe deployment.

This record is not legal advice. It is the project's provenance record for an owner-authorized, prospective retirement decision.
